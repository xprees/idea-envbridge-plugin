Reports problems with env-spec decorator comments in .env files (the format of varlock's .env.schema), for example: 
# @required @sensitive @type=string(startsWith=sk-)
SERVICE_X_API_KEY=

Reported: malformed decorator comments, unknown or misspelled decorators (with a fix), root decorators outside the header and variable decorators inside it, repeated decorators, @required together with @optional (and @sensitive with @public), invalid @type values, and literal values that don't match their @type. Only files that use decorators are checked.

EnvBridge applies @required, @optional, @sensitive, @public, @internal and @type when it launches a run configuration that reads the file.
