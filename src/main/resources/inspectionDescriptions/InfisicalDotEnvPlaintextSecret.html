Reports plaintext values in .env files for variables that exist as secrets in the bound folder of the secret manager.

The quick fix replaces the value with a reference such as DB_PASSWORD=infisical://DB_PASSWORD (or the bound provider's form, e.g. vault://…, op://…, doppler://…). Run configurations that attach the file, and Node.js tools (Nuxt, Vite, Next.js) that read .env by themselves, then get the secret when launched from the IDE, and the file no longer holds it.
