Reports secrets that are missing in the environment the project is bound to (Secrets for Infisical):
  • an infisical://KEY reference whose key doesn't exist in the environment it reads;
  • code reading an environment variable (System.getenv("KEY"), process.env.KEY, os.environ["KEY"], ${KEY}, …) that other environments of the project define but the bound one doesn't.

Ordinary variables that no environment defines (such as PATH) are never reported. The quick fix switches the project to an environment that has the key.
